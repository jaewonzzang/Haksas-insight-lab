# 추천도 알고리즘 요약

> 요약본. 상세 근거·실측·예상 질문 답변은 `scoring_rationale.md`. 구현: `engines/recommender/`.

## 한 줄 요약

추천 점수는 **전부 결정론**이다 — LLM은 결과를 1~2문장으로 통역만 하고, 점수·순위·판정에는 개입하지 않는다.

## "유사한 학생"의 정확한 기준 (두 가지 — 서로 다름)

**① 카드 A 코호트 선호도 — Jaccard 가중 투표.** 별도의 "유사 학생 N명"을 뽑지 않는다.
내 이수 집합 `T`, 졸업생 i의 이수 집합 `A_i` (둘 다 **현행 교과과정 과목만** 계산):

```
w_i = |T ∩ A_i| / |T ∪ A_i|          (Jaccard 유사도 — 겹침 0이면 집계 제외)
코호트(후보 c) = Σ[c를 들은 i의 w_i] / Σ[전체 w_i] × 100
```

즉 졸업생 전원(14,942명)이 투표하되 **나와 이수 이력이 겹칠수록 표가 크다**. 학과 필터 없음 —
유사도 가중이 코호트를 대신한다. 단순 인기순이 아니지만 IDF 보정은 없어 필수과목이 유리한 한계 있음.

**② 카드 D "유사 이수 경로 30명" — TF-IDF 코사인 상위 30명.** 졸업생별 이수 과목ID 집합을
문서로 보고 TF-IDF 벡터화 → 내 이수 집합과 **코사인 유사도 상위 30명**(이력 완결자만). ①과 다른 기준이다.

## 4요인 가중치 (총합 100 — 2026-07-22 확정) — 각 요인의 공식과 근거

| 순위 | 요인 | 가중치 | 요인 점수 공식 (0~100) | 이 크기를 준 이유 |
|---|---|---|---|---|
| 1 | 코호트 선호도 | **40** | 위 ① Jaccard 가중 투표 | 검증된 **행동** 증거(실제 수강) — 가장 직접적, 단일 최대 |
| 2 | 콘텐츠 유사도 | **25** | 내 이수과목 텍스트(과목명+설명+개요) TF-IDF **중심 벡터** ↔ 후보 코사인 ×100 | **내 이력** 기반 개인화 — 행동보단 간접("비슷함 ≠ 좋은 다음") |
| 3 | 학년 적합도 | **20** | 권장학년 일치 100 · ±1학년 50 · 그 외 0 | 교육과정 **규범** — 개인화 아님 |
| 4 | 사용자 선호 매칭 | **15** | 선택한 선호별 티어 점수의 평균 — 팀플(필수100/선택50) · 저출석(비중≤10% 100/≤20% 50) · 발표(≥20% 100/>0 50) | **자기신고**(말) + 과목의 '방식'일 뿐 — 가장 약함 |

- **순서 원리**: "증거의 직접성 × 개인화" — 행동 > 내 이력 > 규범 > 자기신고. 크기는 이 순위대로 총합 100 배분.
- 콘텐츠(2위) > 학년(3위)은 **원칙 선택** — 홀드아웃 예측력은 반대(학년>콘텐츠)였고, 그 비용을 실측으로 안다(아래).

## 결합 공식 (순서 고정)

```
① 각 신호를 그룹(전공/교양) 내 최대값 기준 0~100 리스케일   ← 그룹 내 상대 강도
② 점수 = Σ(wf × sf) / Σwf                                  ← 있는 요인만 — 빠지면(선호 미입력·계획서 없음) 재정규화
③ − 선수 감산 = 40 × (1 − 선수 충족률)                      ← AND/OR 트리 충족 비율, 최대 40점
④ 수강제한 차단: 금지 목록 + "X과(1전공)만 가능" 화이트리스트 시행 → 0~100 클램프
```

필터(③④)를 결합(②) 이전에 두면 협업필터링 신호가 망가지므로 순서는 고정. 총합 100이라 4요인 다 있으면 명목=실효.

## 등급 컷오프 (80 / 60)

강추(80+) · 고려(60+) · 유보. 등급별 실수강률 **39.6% > 18.1% > 1.2%** 단조 분리 → 컷오프 유지.

## 어떻게 검증했나

졸업생 이력에서 **마지막 정규학기를 숨기고** 이전 이력만으로 추천 → 실제 수강을 맞히는 홀드아웃(343케이스).
현 가중치: Recall@8 0.391 · 강추 실수강률 39.6%. ⚠️ **정직 노트**: 홀드아웃 최적값(구 35/10/30/15,
R@8 0.407)이 따로 있고, 현 값은 재현율을 소폭 양보하고 **해석 가능성·강추 정밀도(39.6% vs 34.0%)를
우선**한 원칙 기반 선택 — 발표에서 숨기지 않는다.
