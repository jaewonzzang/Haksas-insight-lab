# 추천도 알고리즘 요약

> 3분 요약본. 상세 근거·실측·예상 질문 답변은 `scoring_rationale.md`.

## 한 줄 요약

추천 점수는 **전부 결정론**이다 — LLM은 결과를 1~2문장으로 통역만 하고, 점수·순위·판정에는 개입하지 않는다.

## 계산 파이프라인 (순서 고정)

```
콘텐츠 유사도 + 코호트 선호도 → 4요인 가중 결합(hybrid) → 선수과목 감산(최대 40) → 수강제한 차단
```

필터를 결합 이전에 두면 협업필터링의 코호트 신호가 망가지므로 순서는 고정이다.

## 4요인 가중치 (총합 100 — 2026-07-22 확정)

| 순위 | 요인 | 가중치 | 이 크기를 준 이유 |
|---|---|---|---|
| 1 | 코호트 선호도 | **40** | 나와 이수 이력이 비슷한 선배가 **실제로 들은** 과목 — 검증된 행동 증거, 단일 최대 |
| 2 | 콘텐츠 유사도 | **25** | 내가 이미 들은 과목과 내용이 이어짐(TF-IDF) — 내 이력 기반 개인화 |
| 3 | 학년 적합도 | **20** | 교육과정이 권장하는 이수 시점 — 구조적 규범 |
| 4 | 사용자 선호 | **15** | 팀플·발표 등 자기신고 — 과목의 '방식'이지 적합의 핵심은 아님, 가장 약함 |

- **순서 원리**: "증거의 직접성 × 개인화" — 행동(코호트) > 내 이력(콘텐츠) > 규범(학년) > 자기신고(선호).
- 요인이 빠지면(예: 선호 미입력) 남은 요인으로 **재정규화**. 총합 100이라 4요인이 다 있으면 명목 = 실효.
- 코호트는 단순 인기순이 아니다 — 이수 이력 **Jaccard 유사도 가중**이라 "누구나 듣는 과목"보다 "나 같은
  사람이 듣는 과목"이 올라간다. 단 IDF 보정은 없어 필수과목이 구조적으로 유리한 한계는 있다.

## 등급 컷오프 (80 / 60)

강추(80+) · 고려(60+) · 유보. 등급별 실수강률이 **39.6% > 18.1% > 1.2%** 로 단조 분리 → 컷오프 유지.

## 어떻게 검증했나

졸업생 이력에서 **마지막 정규학기를 숨기고** 이전 이력만으로 추천을 돌려, 숨긴 학기의 실제 수강을 맞히는
홀드아웃(343케이스). 현 가중치 성능: Recall@8 0.391 · 강추 실수강률 39.6%.

⚠️ **정직 노트**: 홀드아웃 최적값(구 35/10/30/15, R@8 0.407)이 따로 있고, 현 가중치는 재현율을 소폭
양보하는 대신 **해석 가능성과 강추 정밀도(39.6% vs 34.0%)를 우선**한 원칙 기반 선택이다. 발표에서 숨기지 않는다.

## 알아둘 한계

- 홀드아웃의 정답은 "수강했다"까지 — 만족했는지·도움이 됐는지는 아니다.
- 평점(강의평가)·졸업요건 진척 요인은 재료가 없어 제외 — 요건 진척은 SAINT 포털에 위임.
- 선수과목 감산의 커버리지는 317/1,807과목(17.5%) — 강의계획서 산문 파싱의 한계.
- "AI가 가중치를 정했다"는 틀린 프레이밍 — 결정론 설계 + 홀드아웃 실측이며 LLM 무관.
