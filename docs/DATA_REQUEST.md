# 학사지원팀 자료 요청 리스트

> S-Compass(학생 맞춤 학업 분석 대시보드)에 필요한 자료 목록. 2026-07-13 기준.
> 요청 전 참고: 자료 제공 가부가 불확실하므로(타 팀 형평성 이슈) **항목별 우선순위와 미수령 시 대안**을 함께 적음 — 1번만 받아도 핵심 기능이 완성된다.

## 공통 원칙 (요청 시 함께 전달)

- **개인정보 불필요**: 이름·학번·연락처 없이 **임의 익명 ID**로 충분. 진로도 회사명이 아닌 분류(직군/진학 구분)면 됨.
- **형식 무관**: Excel/CSV/PDF 등 보유하신 원본 그대로 주시면 됨 (내부에서 변환·정제 — 컬럼명이 달라도 어댑터로 흡수하도록 설계돼 있음).
- **범위 축소 가능**: 전체가 어려우면 아래 각 항목의 "최소 범위"만이라도.

## 1. 졸업생 학적·진로 데이터 ★ 최우선 (이것 하나가 핵심)

**용도**: 추천의 근거가 되는 "선배들의 실제 수강 경로"(카드 A 코호트 신호), 다전공 경로 분포(카드 C), 유사 선배 진로 클러스터(카드 D), 추천 가중치 검증 — 현재는 합성 데이터 240명으로 대체 중이라 이 자료가 와야 결과가 실제 의미를 가짐.

**졸업생 1명당 필요한 항목** (익명 ID 기준으로 연결만 되면 파일이 나뉘어 있어도 됨):

| 항목 | 상세 | 필수 여부 |
|---|---|---|
| 익명 ID | 임의 부여 번호 (학번 아님) | 필수 |
| 소속 학과/학부 | 원문 그대로 (예: 아트&테크놀로지학과) | 필수 |
| 전공 구성 | 1전공 + 복수/부/연계전공 명칭 목록 | 필수 |
| 이수 과목 목록 | 과목코드(또는 과목명) 전체 | 필수 |
| 이수 학기 정보 | 각 과목을 몇 학년/몇 학기에 들었는지 | 권장 (수강 순서 분석용) |
| 전공별 이수학점 | 1전공/2전공별 이수 학점 수 | 권장 (카드 C 평균 학점) |
| 졸업 후 진로 | 구분(취업/대학원 진학/기타) + 세부(직군 분류 또는 진학 대학원·전공) | 필수 (카드 D) |
| 입학·졸업 연도 | | 권장 |

**최소 범위**: 지식융합미디어학부 소속 학과(아트&테크놀로지·미디어&엔터테인먼트·신문방송) + 컴퓨터공학과, 최근 3~5년 졸업생.
**미수령 시**: 합성 데이터 유지 — 시연은 가능하나 "실제 선배 데이터 기반"이라고 말할 수 없음.

> **⚠️ 2026-07-15 수령한 "2024·2025 수강정보" 파일에서 확인된 문제 — 재요청 시 반드시 반영:**
> 1. **개인 식별 붕괴 (치명)**: 학번을 `1985***6`처럼 가운데 자리 마스킹 → 같은 패턴의 **여러 학생이 하나로 병합**됨 (한 마스킹ID가 최대 39개 학과·975개 과목을 "수강"; (학번,학기) 그룹당 중앙 30과목). 개인별 이력 복원 불가 → 코호트 신호 사용 불가.
>    → **요청**: 마스킹 대신 **학생 1명당 고정된 임의 대체키 1개**(가명처리). 같은 학생의 모든 행 = 같은 키, 다른 학생 = 반드시 다른 키.
> 2. **단면 vs 개인 이력**: 받은 건 "2024·2025에 열린 수강의 단면"이라 개인의 1학년~졸업 궤적이 없음.
>    → **요청**: **졸업생 1명당 입학~졸업 전체 학기 수강 이력**(n개년 졸업 코호트). 정확한 학기(예: 2021-1학기) 포함.
> 3. **과목코드 부재**: 수강강좌명만 있어 코드 매핑에서 ~5% 손실(행 기준 95% 매칭).
>    → **요청**: 가능하면 **과목코드 병기**.
> (받은 파일 = 암호 xls. 재제공 시 암호·형식은 무방 — 위 3개만 지켜지면 됨. 좋았던 점: 전공구분·과목구분·소속학과·수강연도/학기 컬럼은 그대로 유지 요청.)

## 2. 2026-2학기 개설교과목정보 ★ 시기 되면 필수

**용도**: 추천 대상 학기(2026-2)의 실제 개설 과목 목록. 현재는 2025-2 개설 기준으로 근사 중 — 신설·폐강이 반영 안 됨.
**상세**: 기존에 확보한 "개설교과목정보" 파일(2024-2 ~ 2026-1)과 **같은 양식**의 2026-2 버전 1개. 공개 예정 자료라 형평성 부담이 가장 적을 것으로 예상.
**미수령 시**: 2025-2 근사 유지 (공개되는 시점에 수강신청 사이트에서 자체 확보 가능).

## 3. 교양 영역 매핑표

**용도**: 교양 추천에 영역 표시(공통선택 4영역/자유선택 9영역) + 졸업요건(트랙 충족도) 점수 요인 활성화 — 현재 이 요인은 데이터 부재로 꺼져 있음.
**상세**: 전인교육원 개설 과목 ↔ 소속 영역 대응표 (요람/수강편람에 있는 수준이면 충분).
**미수령 시**: 요람(공개 자료)에서 수작업 추출 가능 — 학사팀 자료면 정확도·수고가 줄어드는 정도.

## 4. 강의계획서 일괄 (PDF)

**용도**: ① 선수과목 정보 → 선이수 충족도 점수 (파이프라인 구축·실PDF 검증 완료), ② 수업 개요 텍스트 → 과목 내용 유사도 신호(현재 무력), ③ 팀플/평가 방식 → 학생 선호 매칭 요인.
**상세**: 아트&테크놀로지학과·컴퓨터공학과·전인교육원 과목의 최근 학기(2025-2, 2026-1) 강의계획서 PDF. **파일명에 과목코드 포함** 요청 (동명 과목 구분 — 예: `CSE4010_컴퓨터아키텍쳐.pdf`).
**미수령 시**: 재학생 계정으로 수강신청 사이트에서 개별 다운로드 가능 (수량이 많아 일괄 제공이 크게 도움될 뿐).

## 5. 과목별 강의평가 점수 (민감 — 안 되면 무방)

**용도**: "시간 가중 평점"(최근 학기 수강생 만족도) 점수 요인 활성화 — 6개 요인 중 유일하게 다른 경로가 없는 항목.
**상세**: 과목코드별 강의평가 평균 점수, 최근 2~4개 학기. 과목 단위 집계값이면 충분 (교수 개인 식별 불필요).
**미수령 시**: 해당 요인은 N/A 유지 (가중치가 나머지 요인으로 자동 재분배되도록 구현돼 있어 시스템 동작에는 지장 없음).

## 플랜 B — 학사팀 자료를 못 받는 경우 (공개 자료만)

전제: **강의계획서 2개년치는 공개 정보라 확보 확정** (2026-07-13 확인). 이 경우 추천의 축을 "선배 수강 데이터(협업)"에서 "**강의계획서 콘텐츠 기반**"으로 옮긴다.

| 기능 | 플랜 B 가능 여부 | 재료 |
|---|---|---|
| 카드 A — 콘텐츠 유사도 | ✅ 주력 신호로 승격 | 강의계획서 수업 개요 텍스트 (파서에 개요 추출 추가 필요) |
| 카드 A — 선이수 충족도 | ✅ | 강의계획서 선수과목 (`build_syllabus_prereqs` 검증 완료) |
| 카드 A — 사용자 선호 매칭 | ✅ | 강의계획서 팀플 비중·평가방식·출석 비중 ↔ 입력 폼 선호 |
| 카드 A — 트랙 충족도 | ✅ | 요람 교양 영역·졸업요건 (공개) |
| 카드 A — 학년 적합도 | ✅ (활성) | 개설교과목정보 수강/권장학년 (공개) |
| 카드 A — 코호트 선호도 | ❌ 합성 유지 | 졸업생 데이터 — 공개 대체재 없음 |
| 카드 C 다전공 분포 / 카드 D 유사 진로 | ❌ 합성 유지 | 대안: "합성 데이터" 명시 표기, 또는 소규모 동문 설문(수십 명) 절충 |

결론: 플랜 B에서도 카드 A(추천)는 요인 6개 중 5개가 실데이터로 동작 — 실질적 추천 가능. 카드 C/D만 "실제 선배 기반" 서사를 잃는다. 어느 쪽이든 **강의계획서 파이프라인 확장(개요 텍스트 추출 → 콘텐츠 신호, 팀플·평가 → 선호 매칭)은 공통 선행 작업**이라 학사팀 답변과 무관하게 진행 가치가 있음.
