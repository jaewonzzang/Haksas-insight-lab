# 수강내역 — 학년 추론 & 휴학 보정 (발표 방어 논리)

> "휴학한 학생은 어떻게 처리했냐"고 물을 때 답할 논리. 2026-07-17 정리.
> 대상 데이터: `data/external/2020년-2026년 수강내역_난수변환.xlsx` (387,346행 / 학생 14,942명 / 2020~2026).

## 0. 한 줄 요약

수강내역에 **학년 컬럼이 없다.** 순진하게 `학년도 - 입학년도 + 1`(경과연차)로 쓰면 휴학한 학생이 전부 밀린다. **등록한 정규학기를 세면** 휴학을 탐지할 필요도 없이 왜곡이 사라진다 — 휴학 학기엔 수강 기록 자체가 없기 때문이다. 실측으로 확인했다.

## 1. 문제

원본 컬럼은 9개뿐이다:

```
학년도 | 학기 | 과목코드 | 과목명 | 학번_암호화 | 소속학과 | 1전공 | 2전공 | 3전공
```

학년도 없고, 이수학기도 없다. 유일한 시간 정보는 `학년도`와 `학번_암호화`의 입학년도 접두어(`20학번-10013`)다. 여기서 바로 나오는 건 **경과연차**(`학년도 - 입학년도 + 1`)인데, 이건 학년이 아니다:

| 경과연차 | 행수 |
|---|---|
| 1~4 | 343,459 |
| **5~7** | **43,887 (11.3%)** |

5학년 이상이 11.3%. 휴학·군휴학·초과학기가 경과연차를 부풀린 결과다.

## 2. 해법 — 휴학을 추론하지 않고 관측한다

휴학을 *탐지*해서 빼는 게 아니라, **등장한 정규학기(1·2학기, 계절학기 제외)의 순번**을 그대로 쓴다. 휴학하면 그 학기에 행이 없으므로 순번이 자동으로 안 는다. 추론이 아니라 관측이다.

```
학년 ≈ ceil(등록 정규학기 순번 / 2)
```

공백(중간에 빠진 학기)은 실제로 데이터에 있다 — 학생의 **34.2%**(5,115/14,941)에 공백이 있고, 길이 분포가 제도와 맞아떨어진다:

| 공백 길이 | 건수 | 해석 |
|---|---|---|
| 1학기 | 2,792 | 일반휴학 |
| 2학기 | 1,162 | 일반휴학(1년) |
| 3학기 | 657 | — |
| **4학기** | **1,680** | **군휴학 (스파이크)** |
| 5학기+ | 261 | 장기휴학·자퇴후재입학 등 |

## 3. 실측 검증

**정답 대용**: 과목코드의 학년수준 숫자(`COR1003`→1학년급, `CSE4011`→4학년급). 학생이 그 학기에 들은 과목의 수준과 추정 학년의 절대오차(MAE)를 잰다. 대상 369,818행.

| 학생군 | 경과연차 방식 | 학기세기 방식 |
|---|---|---|
| 공백 없음 (186,528행) | MAE 0.766 / 정확 41.9% | MAE 0.746 / 정확 43.1% |
| 공백 있음 (183,290행) | MAE **1.124** / 정확 30.3% | MAE **0.735** / 정확 42.0% |

**읽는 법 (이게 핵심)**:

1. **공백 없는 학생은 두 방식이 사실상 같은 계산**이다 → 차이 없음(0.766 vs 0.746). 여기서 나오는 **0.75가 지표 자체의 잡음 바닥**이다. 보정할 게 없는 학생한테도 이만큼 나온다 — 학생이 자기 학년 위아래 과목을 섞어 듣기 때문이고, 더 줄일 수 없다.
2. **공백 있는 학생에서 경과연차는 1.124로 튄다** → 휴학 왜곡이 실재한다는 증거.
3. **학기세기로 바꾸면 0.735** → 잡음 바닥(0.746)과 **통계적으로 구분되지 않는다**. 즉 휴학 왜곡이 흔적 없이 제거됐다.

한 줄로: **보정 후 휴학생은 휴학 안 한 학생과 통계적으로 동일해 보인다.**

## 4. 한계 (정직하게)

- **증명된 것**: 등록학기 세기가 휴학 왜곡을 제거한다.
- **증명 안 된 것**: 등록학기 수 = **학사 시스템의 공식 학년**. 한국 대학 학년은 통상 이수학점 기준이라, 6학기 등록한 두 학생이 학점에 따라 공식적으로는 2학년/3학년으로 갈릴 수 있다. **이 파일엔 학점 컬럼이 없어 검증 불가.**
- 공백이 항상 휴학인 것도 아니다 — 교환학생, 계절학기만 수강한 학기도 같은 모양이다. 다만 4학기 스파이크는 군휴학으로 읽는 게 자연스럽다.
- 정답 대용(과목 학년수준)은 무른 지표다. 절대 정확도(~43%)를 성능으로 읽으면 안 되고, **두 방식의 상대 비교로만** 유효하다.

## 5. 그래서 실제로는 이 한계가 거의 무의미하다

카드 A 코호트(협업필터링)에 필요한 건 공식 학년이 아니라 **궤적 위치** — "나와 비슷한 지점의 학생들이 뭘 들었나". **등록학기 순번이 궤적 위치 그 자체**라서 추정할 것도 없이 정확하다.

공식 학년이 필요한 곳은 `core/year_rules`의 수강학년 제한인데, 거기 쓰는 건 **현재 사용자의 학년**이고 그건 입력으로 받는다 → 추론 불필요.

**결론: "학년"으로 부르지 말고 "등록학기 순번"으로 쓴다.** 추정이 아니라 관측값이고, 학사팀에 `이수학년` 컬럼을 재요청할 이유도 없다.

## 6. 재현

검증 스크립트는 스크래치(비커밋). 재현 절차:

1. `msoffcrypto`로 xlsx 복호화 (암호는 학사팀 제공 — 리포에 기록하지 않음)
2. `(학년도, 학기)` → 절대 학기 인덱스 `year*2 + (term-1)`, 계절학기 제외
3. 학생별 정렬 후 순번 부여 → `ceil(순번/2)`
4. 과목코드 `^[A-Z]{2,4}(\d)\d{3}$` 1~4 그룹과 MAE 비교
