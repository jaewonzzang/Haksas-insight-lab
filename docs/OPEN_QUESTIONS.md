## 결정 완료 (참고용)

- **백엔드 패키지 관리** → `pyproject.toml` + uv. `requirements.txt`는 `uv export`로 변환.
- **DB 접근** → raw `sqlite3` + `app/db/schema.sql` 단일 스키마. ORM 없음.
- **프론트 빌드** → Vite + React + TypeScript. 프로토타입은 디자인 토큰만 추출, 원본은 `frontend/legacy/` 보존.
- **카드 구성** → A (추천 과목, 가로 2칸), C (다전공 경로), D (유사 졸업생 진로). 카드 B 제거.
- **학과명 정규화** → 원문 보존, 추천 풀 산출 시점에 합집합 적용.
- **수강 제한 패턴** → 4가지 정형 (`allowed`, `forbidden`, `major_only_allowed`, `major_only_forbidden`). 비정형 0건.
- **다학기 저장** → course_offerings 테이블 신설 (courses 는 latest-wins 1행, 개설 이력 분리). 6테이블.
- **카드 A 응답 구조 (구 A2)** → 통합 `DashboardResponse` 유지. `frontend/src/types/api.ts` 확장 계약이 진실원, 백엔드 `schemas/cards.py`가 미러 (2026-07-06 확정).
- **"왜?" 패널 데이터 (구 A13)** → 전용 why 필드 신설 없이 기존 `factors`/`why_summary`/`cluster` 필드를 백엔드가 결정론 점수 분해로 채움 (2026-07-06 확정).
- **트랙 충족도(졸업요건 진척) 요인 (구 A6 일부)** → 요람 기반 재구현 안 함 (2026-07-15). 학교 SAINT 포털이 학생별 전공필수·교양·전공선택 이수/잔여를 정확히 제공 → 위임. 요인은 6요인 설계 슬롯으로 유지하되 N/A(향후 포털 로그인 데이터 연동 시 활성). 가중치·수치 현행유지.
- **평점(강의평가) 요인** → 영구 드롭 (2026-07-15). 유일하게 대체 경로가 없는 요인 → 요청 철회. 발표는 **5요인**(코호트·콘텐츠·선호·트랙·학년)으로 프레이밍. `weights.py` 수치 현행유지(평점은 데이터 없어 런타임 자동 흡수), 설명자료·발표에서만 5요인 표기.

## 미결정 — 본격 구현 전에 정해야 함

### A1. 졸업생 데이터 실 컬럼 매핑 (잔여) — ✅ 2차 수령분 사용 가능, 코호트 해금
- **부분 결정**: 잠정 프레임 확정 — `app/adapters/alumni_types.AlumniRecord` (코어 `alumni_id`+`department`, 나머지 Optional). 스펙: `superpowers/specs/2026-06-29-alumni-data-frame-design.md`.
- **2026-07-15 블로커 (해소됨)**: 1차 수령분("2024·2025 수강정보")은 학번 패턴 마스킹(`1985***6`)으로 여러 학생이 병합되어 개인별 이력 복원 불가 → 사용 불가 판정. 사용자가 삭제하고 2차분으로 교체.
- **2026-07-17 2차 수령분 = 사용 가능**: `data/external/2020년-2026년 수강내역_난수변환.xlsx` (암호 걸림, 387,346행 / **학생 14,942명** / 2020~2026 / 단일시트 9열). 재요청 조건 대비:
  - **① 고정 대체키 → 충족.** `20학번-10013` 형태, 난수부분 14,942개 전역 고유(코호트 간 재사용 0), **10,649명이 2개 이상 연도에 동일 ID로 등장** → 개인 이력 추적 가능 → **코호트(협업필터링) 실데이터화 가능**.
  - **② 입학~졸업 전체 이력 → 부분.** 2020년부터라 20학번은 4년치 확보, 19학번 이전 없음. 경과연차 1~4 완주 2,607명(20~23학번). 2026은 1학기+하계만(우측 절단).
  - **③ 과목코드 병기 → 충족.** 분반 접미어(`-12`) 제거 시 `courses` DB와 **행 95.3% 조인**, DB 과목 1,807개 중 1,794개(99.3%) 커버. 미매칭은 대부분 폐강 교양.
- **학년 컬럼 없음 → 해결됨**: 등록 정규학기 순번으로 대체(휴학 왜곡 실측 제거, MAE 1.124→0.735). 근거·한계: `docs/enrollment_inference.md`. 학사팀 `이수학년` 재요청 불필요.
- **잔여 (신규 발견)**: 2차분에 **진로 컬럼 없음** → 카드 D는 mock 유지(A14). **과목구분(전필/전선/교양) 없음** → `Major.credits` 산출 불가 → 카드 C 추가학점 N/A(A15). 1차분엔 있던 컬럼이라 재요청 시 후보.

### A15. 소속학과 변경 학생 기준 시점 (신규 2026-07-17)
- 2차 수령분에서 **2,258명(15%)**의 `소속학과`가 기간 중 변경됨. 전과인지 학부→학과 분리인지 미확인.

### A16. 학과명 표기 분열 (2026-07-17 — 해결, 커버리지 100%)
- 수강내역 `소속학과`가 `courses.db` 학과명과 갈려 코호트 대조가 빗나가던 문제(14,942명 중 5,036명 미매칭). `dept_normalizer`에서 해결 — **졸업생 소속 해석 66.3% → 100%**, 오합침 0.
  - **표기 별칭** 27종 → `DEPT_ALIASES` (`X전공`↔`X학과`, 원본 잘림, 학부↔전공).
  - **대학 계층** → `DEPT_COLLEGES`(사용자 제공 조직도 = 9개 대학 / 32개 학과, 전부 DB 실재 확인) + `FACULTY_COLLEGES`. 기존 `DEPT_UNIONS` 하드코딩 특례는 여기에 흡수돼 삭제.
- **결정: 계열 입학 표기(`인문학부`·`사회과학부`·`지식융합미디어학부`·`인문계`·`사회과학계`)는 대학까지만 내리고 학과 코호트에서 제외.**
  - 근거(실측): 이 표기로 기록된 **861명 전원이 1~2학년 = 학과 선택 전**. 학과 코호트에 넣으면 전원 "단일전공 유지"라 카드 C 다전공 분포가 오염된다.
  - 재검토 조건: "1~2학년도 선배 표본에 포함" 요구가 나오면 `canonical`에서 대학→학과 확장 방향을 열면 됨.
- **조직도 ↔ DB 이름이 다른 지점** (조직도는 학생 소속, DB는 과목 개설 주체 기준):
  - 조직도 `영문학부` = DB `영미어문전공` (DB에 `영문학부` 과목 0개). `영문학부`·`영문학부(영미어문전공,`·`영미문화계`·`영미어문전공` 4종을 `영미어문전공` 하나로 모음(718명).
  - 조직도 `경영학부` = DB `경영학부(경영학전공)`.
  - 조직도 `로욜라국제대학`은 `글로벌한국학부`만 두는데 DB엔 `글로벌한국학과`(25과목)·`글로벌한국학부`(20과목)가 **둘 다 개설 주체로 존재**. `글로벌한국학전공`(26명)은 조직도 따라 `글로벌한국학부`로. 두 DB 학과를 합치면 추천 풀이 한쪽으로 쏠려 손실이 나므로 **합치지 않음** — 개명 이력 확인 시 재검토(영향 학생 49명).
- **영향 범위**: 카드 C 코호트 표본, 카드 D "학과 코호트 일치" 지표. **카드 A 코호트 선호도는 무관**(`collaborative`가 학과를 안 봄).
- **잔여**: DB에만 있고 조직도엔 없는 연계전공 15종(`공공인재 연계전공` 등)·`전인교육원`·`융합교육원`은 대학 매핑 없음. 과목 개설 주체일 뿐 학생 소속이 아니라 현재 구조에선 무해.
