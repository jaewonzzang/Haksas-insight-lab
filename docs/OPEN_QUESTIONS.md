    | 심리학과 | 110 / 65% | 94 / 64% | 77 / 61% |

    단, "4학년 후 휴학 중인 학생이 완결로 잡힘" 자체의 직접 검증은 재학/휴학/졸업 컬럼이 없어 여전히 불가 — 데이터 한계로 발표에서 명시.
  - **카드 A는 전체 14,942명 유지** — 코호트 선호도는 재학생 이수 이력도 유효한 신호(오히려 최근 패턴). 의도된 차이.

### A3. 강의계획서 PDF 통합 시점

- 데이터/시간 제약 보고 결정.
- **2026-07-15**: 프로필 B~D는 학과·학년·전공구성을 **폭넓게** 다양화하는 방향. 단 실데이터는 학사팀 요청 수령 후 주입 → **지금은 껍데기(placeholder)만** 구현하고 데이터는 나중에.

### A6. 카드 A 교양 영역 매핑 (표시용으로 축소)
