# S-Compass 기술자문 브리핑 (2026-07-22)

> 확인받을 3축: **① v2 재정의 타당성 · ② 이수현황(성격) 접근 · ③ 남은 개발 우선순위.**

## 30초 요약

**"무엇을 들을지"는 선배 실수강 데이터로 객관 추천까지 완성.** 그러나 **"졸업까지 남은 경로를 어떤 순서로"라는 구체적 이수경로는 아직 못 감** — 잔여 졸업요건 데이터가 열쇠인데 우리가 요람 파싱하면 부정확, 학교 SAINT가 이미 정확히 안다. 그래서 (A) 이수현황을 껍데기로 두고 v1을 구체화할지, (B) 문제를 **v2(주관 리뷰 의존 → 객관 데이터 추천)로 재정의**해 완성된 코호트 추천을 핵심 가치로 세울지를 묻고 싶다.

## 1. 문제 · 해결

| | 문제 | 해결책 |
|---|---|---|
| v1 | 복잡한 이수경로 + 파편적·주관적 데이터 | 구체적 이수경로 추천 |
| **v2** | **주관 리뷰(에타 등) 의존 수강신청** | **객관 데이터(선배 실수강) 기반 추천** |

핵심 설계: **점수·판정은 결정론 + ML, LLM은 통역만.** 입력 정형 폼 → 정형 대시보드(카드 A/C/D + "왜?"). **챗봇 아님.**

## 2. 무엇을 만들었나 (현재 상태)

- **스택**: FastAPI · raw sqlite3 · uv / scikit-learn(TF-IDF·협업필터링) / Vite+React+TS. LLM=Claude(통역).
- **카드 A** 추천(전공·교양 4+4, 4요인+홀드아웃 튜닝) · **카드 C** 다전공 경로 분포+추가학점 · **카드 D** 유사경로 중 대학원 과목 이수율 — **3장 전부 실데이터 연동 완료.** (카드 B 졸업진척도는 SAINT와 중복이라 제거.)
- **실데이터**: 졸업생 수강내역 14,942명(2020~2026). 카드 A는 전체, 카드 C는 이력 완결자 1,919명.

## 3. 가중치 핵심 (카드 A) — 🔴 2026-07-22 재설정

**총합 100 기준으로 재설정** — 4요인 다 있으면 명목=실효 (기존 합 0.90의 "코호트 명목 35 vs 실효 39" 괴리 제거). 순서: **코호트 > 콘텐츠 > 학년 > 선호.**

| 요인 | 가중치 | 숫자의 의미 |
|---|---|---|
| 코호트 선호도 | **40** | 나와 비슷한 이력의 선배가 실제로 들은 과목 — 검증된 행동 증거, 단일 최대 |
| 콘텐츠 유사도 | **25** | 내가 이미 들은 과목과 내용이 이어지는 과목 — 내 이력 기반 개인화 |
| 학년 적합도 | **20** | 권장 이수 학년 적합 — 교육과정 규범 |
| 사용자 선호 | **15** | 팀플·발표 등 자기신고 선호 — 방식, 가장 약함 |

- **순서 원리**: "증거의 직접성 × 개인화" — 행동(코호트) > 내 이력(콘텐츠) > 교육과정 규범(학년) > 자기신고(선호).
- **숫자 의미**: 각 값 = 4요인 다 있을 때 적합 점수(100점)에서 그 신호의 몫. 요인이 빠지면(예: 선호 N/A) 남은 요인으로 재정규화. 이후 **선수 감산(최대 40)·수강제한 차단**이 그 뒤 적용.
- ⚠️ **정직 노트(회의 필수 논의)**: 콘텐츠(2위)를 학년(3위) 위에 둠 = **원칙 기반**이며 **구 홀드아웃(학년>콘텐츠)과는 반대**. **동일 빌드 재측정(343케이스, 2026-07-22):**

  | 가중치 | Recall@8 | Recall@20 | MRR | 강추 실수강률 |
  |---|---|---|---|---|
  | 구 35/10/30/15 (튜닝) | 0.407 | 0.598 | 0.470 | 34.0% (695개) |
  | **신 40/25/20/15 (원칙)** | **0.391** | **0.559** | **0.460** | **39.6% (351개)** |

  → 새 값은 Recall이 약간 낮으나(−1.6~3.9%p) **강추 버킷이 더 좁고 정밀(39.6%)**. **해석가능성↑ ↔ 재현율↓ 트레이드오프** — 회의에서 이 교환을 수용할지 결정. `scoring_rationale.md` 갱신 완료(07-23).
- 방어: "인기순 아니냐" → Jaccard 유사도 가중(IDF 보정 없음 — 한계). "AI가 정했나" → 아니오, 결정론.

## 4. 한계 (먼저 말하는 게 강함)

- **성적(GPA)·과목구분 데이터 없음** → 평점 요인 드롭, 카드 C는 관측 이수학점 근사.
- **구체적 이수경로까지 못 감** (오늘 자문의 출발점) — 졸업요건 진척은 SAINT에 위임.
- **카드 D: "대학원 과목 들음 ≠ 진학함"** — 진로 아닌 진학 지향 행동.
- **표본**: 이력 완결자 12.8%, 소표본(학과별 수십 명대), 재학생 혼합, 2020년~라 좌우 절단.

## 5. 진행 중 — 과목 '성격'(이수구분) 기능

- 오늘 **과목구분표 확보**(과목당 `{전공} {유형}` 분류, 개설 26-1 과목의 99.6% 커버).
- **가능**: 상단 그룹별 이수 학점 카운트(예: `전공필수 21학점`) — **구현 완료(07-23)**: `course_categories` 테이블 + `credit_summary` 응답 + 대시보드 CreditSummary. **카드 A 성격 필터**는 미구현(우선순위 논의 대상). 단일전공 정확·다전공 근사.
- **보류**: "X학점 더" 부족분 계산 — 요건 분모(필요 학점)는 성격표에 없음 → SAINT/요람 영역, 우리가 만들면 열등 복제.

## 6. 자문 난제 (핵심)

1. **전략** — v2 재정의 vs 구체적 경로 되살리기. *(제품 기획 + 학사 도메인)*
2. **다전공 요건 모델링** — 부족분을 어디까지 근사, 중복인정은 위임이 맞나. *(학사 데이터 모델링)*
3. **추천 신호 품질** — 콘텐츠 약세 + 코호트 인기도 편향(IDF 보정). *(추천시스템/IR)*
4. **평가 방법론** — 정답이 "수강했다"까지, 예측력 ≠ 추천품질. *(추천 평가/실험설계)*
   그 외: 데이터 소표본·편향(응용통계) · 카드 D 진로 프록시 정당성.

> 한 명에게 다 묻지 말 것 — **3·4(추천/평가) 트랙**과 **1·2(학사 도메인) 트랙**은 결이 다르다.

## 7. 오늘 물을 질문

1. **v2 재정의**가 후퇴가 아닌 정직한 초점 이동으로 타당한가? 아니면 잔여요건→과목 매핑으로 v1을 살릴 여지가 있나?
2. **이수현황(성격) + SAINT 위임** 접근이 최선인가? 데모에서 이 "껍데기"를 어떻게 프레이밍하나?
3. 성적·요건 데이터가 없는 상태에서 **남은 개발 우선순위**와 한계 커뮤니케이션 방법.
