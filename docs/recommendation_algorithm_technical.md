# 추천 알고리즘 — 기술 명세

> 심사·기술자문 대상 상세 명세. 평이한 설명본은 `recommendation_algorithm.md`,
> 가중치 근거·강건성 실측은 `scoring_rationale.md`. 구현: `backend/app/engines/recommender/`.

## 0. 설계 원칙

추천 점수는 **완전 결정론적 파이프라인**으로 산출한다. 대규모 언어모델(LLM)은 확정된
정형 결과를 1~2문장의 자연어로 사후 통역(post-hoc verbalization)하는 데만 관여하며,
점수 산정·순위 결정·수강 가부 판정의 어느 단계에도 개입하지 않는다. 동일 입력은
항상 동일 출력을 산출한다(재현성 보장).

## 1. 신호 정의 (각 0~100)

카드 A 추천도는 네 개의 독립 신호를 가중 결합한다. 표기: 학생 이수 집합 `T`,
후보 과목 `c`, 현행 교과과정 과목 집합 `C_cur`(2024-2 ~ 2026-1 개설분).

### 1.1 코호트 선호도 (user-based collaborative filtering)

졸업생 코퍼스(N = 14,942)에 대해 사전 코호트 추출 없이 **자카드 유사도 가중 투표**를
수행한다. 졸업생 i의 이수 집합을 `A_i`라 할 때:

```
wᵢ = |T ∩ Aᵢ| / |T ∪ Aᵢ|                     (Jaccard, T·Aᵢ 모두 C_cur 로 사전 교차)
cohort(c) = ( Σ_{i : c ∈ Aᵢ} wᵢ / Σ_i wᵢ ) × 100
```

`wᵢ = 0`인 졸업생(이수 이력 무교집합)은 분자·분모에서 자동 배제된다. 학과 필터를
두지 않으며, 유사도 가중이 연속적(soft) 코호트를 형성해 하드 코호트를 대체한다.
`C_cur` 교차는 교과과정 개편으로 폐지된 과목이 합집합만 부풀려 구(舊)학번 졸업생의
가중치를 부당 감쇄하던 편향을 제거하기 위함이다(구현: `collaborative.py`).

- **한계**: 역문서빈도(IDF) 보정이 없어, 유사도 가중 후에도 이수율이 높은 필수과목이
  구조적으로 유리하다. "겹치는 졸업생을 크게 센다"가 편향을 완화하되 제거하지는 않는다.

### 1.2 콘텐츠 유사도 (TF-IDF centroid cosine)

이수 과목·후보 과목의 텍스트(과목명 + 원문 설명 + 강의계획서 개요, 부분 커버리지)를
말뭉치로 TF-IDF 벡터화한 뒤, **이수 과목 벡터들의 중심(centroid)**과 각 후보 벡터 간
코사인 유사도를 100배 스케일한다(`sklearn.TfidfVectorizer` + `cosine_similarity`):

```
centroid = mean( tfidf(T) )
content(c) = cos( centroid, tfidf(c) ) × 100
```

개인화된 콘텐츠 신호이나 "유사도 ≠ 후속 이수 적합도"라는 본질적 간접성을 갖는다
(구현: `content_based.py`).

### 1.3 학년 적합도

교수 설정 권장학년 집합 `R`(원문 파싱)과 학생 학년 `y`의 이산 계단 함수:

```
year_fit = 100  (y ∈ R)  ·  50  (∃ r∈R, |y − r| = 1)  ·  0  (그 외)
```

교육과정의 구조적 규범 신호이며 개인화 요소가 아니다. 계단값(100/50/0)은 잠정
prior다(구현: `core/year_rules.py`). 신청 불가 학년 과목은 신호 계산 이전에 추천
풀에서 제외된다(표시 금지, `card_a._enrollable`).

### 1.4 사용자 선호 매칭

폼에서 선택한 선호별 티어 점수의 **산술 평균**. 강의계획서 정형 속성에 근거:

| 선호 | 티어 |
|---|---|
| 팀 프로젝트 | 필수 100 · 선택 50 · 없음 0 |
| 낮은 출석 비중 | ≤10% → 100 · ≤20% → 50 · 그 외 0 |
| 발표 비중 | ≥20% → 100 · >0 → 50 · 없음 0 |

자기신고(self-reported) 선호이자 과목의 '진행 방식'에 대한 신호로, 네 신호 중 증거
직접성이 가장 낮다. 강의계획서 결측 과목은 신호에서 제외되어 해당 요인이 N/A 처리된다
(부분 커버리지). 티어 경계는 잠정 prior다(구현: `preference.py`).

## 2. 점수 결합 파이프라인 (순서 고정)

```
① max-scaling      각 신호를 그룹(전공/교양) 내 최댓값 기준 0~100 상대강도로 리스케일
② weighted sum     score_hybrid = Σ (wf · sf) / Σ wf     (present 요인만 — 결측 시 분모 재정규화)
③ prereq penalty   penalty = round( 40 · (1 − fulfillment/100) )  ;  선이수 AND/OR 트리 충족률 기반, 최대 −40
④ restriction gate  블랙리스트/화이트리스트 hard filter → 최종 [0,100] 클램프
```

- **①**: 표시 점수는 절대값이 아니라 그룹 내 상대강도다. "코호트 100"은 "졸업생 전원
  수강"이 아니라 "해당 그룹에서 코호트 신호 최강"을 뜻한다(`hybrid._max_scale`).
- **②**: 결측 요인(선호 미입력·계획서 없음)은 분모 `Σ wf`에서 빠져 나머지 요인이
  비례 재정규화된다. 4요인 총합이 100이므로 전 요인 존재 시 명목 가중치 = 실효 가중치
  (`scoring.score_candidate`).
- **③**: 선이수 미충족은 가산점이 아닌 **감산항**이다. 충족률은 `core/prereq_eval`의
  AND/OR 트리 평가에서 오며, 트리 부재 시 요인 자체가 N/A(감산 없음, `prereq_filter`).
- **④**: 파이프라인 최종 단계. `forbidden`(대상 학과가 학생 전 전공에 포함 시 차단)·
  `major_only_forbidden`(1전공 한정 차단)의 블랙리스트와, `allowed`·`major_only_allowed`의
  화이트리스트(해당 행 보유 과목은 학생이 자격 집합에 들 때만 통과)를 학과별 전공
  지위(1전공/2전공)로 구분 시행한다(`restriction_filter`).

**순서 불변식**: 필터(③④)를 결합(②) 앞에 두면 협업필터링의 코호트 신호가 손상되므로
순서는 고정이다(CLAUDE.md 가드레일).

## 3. 가중치 및 서열 근거

```
FACTOR_WEIGHTS = { 코호트 40, 콘텐츠 25, 학년 20, 선호 15 }   (Σ = 100, 2026-07-22 확정)
```

- **서열 원리**: "증거의 직접성 × 개인화 정도" — 검증된 행동(코호트) > 내 이력(콘텐츠)
  > 교육과정 규범(학년) > 자기신고(선호). 크기는 이 서열대로 총합 100을 배분한다.
- **원칙 ↔ 예측력 괴리 (명시적 고지)**: 서열은 콘텐츠(2위)를 학년(3위) 위에 두나,
  홀드아웃 예측력은 **학년 > 콘텐츠**로 반대다. 상충이 아니라 척도가 다르다 — 서열은
  신호의 *성격*(직접성·개인화), 홀드아웃은 *차기 학기 수강 예측력*을 잰다. 이번 개정은
  크기까지 원칙을 따라(콘텐츠를 학년 위로) 배치했고, 그 대가로 재현율을 소폭 양보하는
  대신 강력추천 버킷의 정밀도를 얻었다(§5).
- 과거 6요인 설계 중 시간가중 평점·트랙 충족도는 산출 재료 부재로 항상 N/A였고
  2026-07-17 `weights.py`에서 제거했다(제거 전후 점수 불변 — 재정규화 분모에서 이미
  배제되어 있었음).

## 4. 등급 임계 (grade cutoffs)

```
강추 ≥ 80  ·  고려 ≥ 60  ·  유보 < 60
```

홀드아웃 표본에서 등급별 실수강률이 **39.6% ▷ 18.1% ▷ 1.2%**로 단조 분리(monotone
separation)됨을 확인해 80/60 임계를 유지한다.

## 5. 홀드아웃 평가 (leave-last-semester-out)

**설계** (`scripts/evaluate_recommender.py`): 정규학기 4개 이상 이수한 졸업생 7,935명
모집단에서 고정 시드(42)로 400명 표본 → 유효 343케이스. 각 졸업생의 **마지막 정규학기를
은닉**하고 이전 이력만으로 추천을 산출, 은닉 학기의 실제 수강(추천 풀과의 교집합)이 상위에
오르는 정도를 측정한다. 평가 대상 본인은 코호트 집계에서 제외해 정보 누수를 차단한다.
지표: Recall@8, Recall@20, MRR, 강력추천 버킷 실수강률.

| 가중치 (코호트/콘텐츠/학년/선호) | Recall@8 | Recall@20 | MRR | 강추 실수강률 |
|---|---|---|---|---|
| 구 35/10/30/15 (2026-07-18 그리드 탐색) | 0.407 | 0.598 | 0.470 | 34.0% (n=695) |
| **신 40/25/20/15 (2026-07-22 원칙)** | **0.391** | **0.559** | **0.460** | **39.6% (n=351)** |

**해석**: 신 가중치는 재현율이 소폭 낮다(−1.6~3.9%p). 이는 예측력이 약한 콘텐츠를
예측력이 강한 학년 위로 올린 원칙적 선택의 정량화된 비용이다. 반대급부로 강력추천
버킷이 더 좁고 정밀해져(39.6% vs 34.0%) 상위 추천의 신뢰도는 상승했다. 채택값은
홀드아웃 최적점이 아니라 **해석가능성을 우선한 값**이다(그리드 재탐색이 아닌 원칙값의
동일 절차 재측정).

## 6. 카드 D의 "유사 이수 경로" — 카드 A와 구분

카드 A의 코호트(§1.1)와 별개 기준이다. 졸업생별 이수 과목 ID 집합을 문서로 보고
TF-IDF 벡터화한 뒤, 학생 이수 집합과의 **코사인 유사도 상위 30명**(이력 완결자 한정)을
추출해 진학 지향(대학원 연계 G코드 이수) 신호를 관측한다. 카드 A는 전원 가중 투표이고
카드 D는 상위 k 추출이라는 점에서 두 "유사 학생"의 정의가 다르다(구현: `engines/career/`).

## 7. 알려진 한계

- **평가 정답의 성격**: 홀드아웃 정답은 "수강 여부"에 국한되며 만족도·학습 효과를
  포착하지 못한다.
- **콘텐츠 표현력**: 과목 ID·텍스트 TF-IDF는 표현력이 제한적이며, 개요 임베딩 도입 시
  예측력 개선 및 가중치 재튜닝 여지가 있다(A10).
- **인기도 편향**: IDF류 페널티 미적용으로 필수과목 쏠림이 잔존한다(§1.1).
- **선이수 커버리지**: 감산항은 1,807과목 중 317과목(17.5%)에만 적용된다 —
  강의계획서 산문의 선수 조건 파싱 한계.
- **잠정 prior**: 학년 계단값·선호 티어 경계는 데이터 검증값이 아닌 설계 prior다.
- **제외 요인**: 강의평가(평점) 데이터 부재로 미반영. 졸업요건 진척은 열등한 요람
  복제 대신 SAINT 포털의 권위 데이터에 위임한다(향후 연동 시 활성).
- **프레이밍 정정**: "AI가 가중치를 학습·결정했다"는 사실과 다르다. 사람이 원칙으로
  설계하고 실데이터 홀드아웃으로 검증한 결정론적 값이며 LLM은 무관하다.
